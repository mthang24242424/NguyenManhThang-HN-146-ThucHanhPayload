Đáp án lựa chọn: Prompt 2

Lý do chọn:

Prompt 2 tốt hơn vì nó xác định rõ:

Mục tiêu: chuyển đổi từ vòng lặp for sang Java Stream API.
Kết quả mong muốn: code ngắn gọn và dễ bảo trì hơn.
Yêu cầu bổ sung: AI phải giải thích lý do tối ưu.

Đây là một prompt có ngữ cảnh, mục tiêu và ràng buộc rõ ràng, giúp AI hiểu chính xác cần thực hiện điều gì và trả về kết quả phù hợp với yêu cầu.

Vì sao Prompt 1 chưa tốt?

Prompt 1 chỉ nói: "Tối ưu hóa code Java này giúp tôi chạy nhanh hơn."

Nhược điểm:

Không nêu rõ muốn tối ưu theo hướng nào (hiệu năng, khả năng đọc, bảo trì hay cấu trúc code).
Không chỉ định kỹ thuật cần sử dụng.
Có thể khiến AI đưa ra nhiều phương án khác nhau hoặc nhận xét rằng code hiện tại đã đủ nhanh vì đã dừng ngay khi tìm thấy số lớn hơn 100.

Do đó, Prompt 1 quá chung chung, trong khi Prompt 2 có mục tiêu và ràng buộc cụ thể nên sẽ cho kết quả chính xác và hữu ích hơn.
