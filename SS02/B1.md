# BÀI 1: Phân tích & Lựa chọn

## Đáp án lựa chọn: **Phương án C**

---

## Phân tích chi tiết

Phương án C là tối ưu nhất vì nó phân bổ công cụ theo đúng thế mạnh và phạm vi ngữ cảnh của từng loại trợ lý, giúp hạn chế tối đa việc chuyển đổi ngữ cảnh (context switching) và tăng năng suất:

- **Tài liệu API (API Guide)**: Web Chat có khả năng lập luận ngôn ngữ mạnh, dễ dàng sinh ra văn bản Markdown rõ ràng, mạch lạc. Đây là công việc thiên về ngôn ngữ, không cần truy cập trực tiếp mã nguồn.
- **Refactor lớp Book trên nhiều file**: Trợ lý lập trình cấp cao (Agentic/Repository-wide Assistant) có khả năng phân tích toàn bộ dự án, hiểu mối quan hệ giữa các file, và tự động đồng bộ thay đổi. Điều này giảm thiểu rủi ro bỏ sót hoặc gây lỗi khi refactor thủ công.
- **Sửa lỗi cú pháp nhỏ**: Inline Code Assistant ngay trong IDE là công cụ nhanh nhất để phát hiện và sửa lỗi tại chỗ, không cần rời khỏi ngữ cảnh đang mở.

Cách kết hợp này giúp giữ ngữ cảnh phù hợp cho từng loại tác vụ, tránh việc phải liên tục sao chép/dán giữa IDE và Web Chat, đồng thời tận dụng tối đa sức mạnh chuyên biệt của từng công cụ.

---

## Nhược điểm của các phương án khác

### Phương án A: Sử dụng Web Chat cho cả 3 tác vụ
- **Hạn chế**: Lập trình viên phải liên tục sao chép nội dung từ IDE sang Web Chat và ngược lại, gây mất thời gian và dễ sai sót.
- **Ngữ cảnh**: Web Chat không có khả năng phân tích toàn bộ repository, nên việc refactor đồng bộ nhiều file sẽ khó chính xác.
- **Năng suất**: Việc sửa lỗi cú pháp nhỏ qua Web Chat là không hiệu quả, vì phải rời IDE để thao tác.

### Phương án B: Sử dụng Inline Code Assistant cho cả 3 tác vụ
- **Hạn chế**: Inline Assistant mạnh trong việc gợi ý và sửa lỗi nhỏ, nhưng không phù hợp để viết tài liệu dài bằng Markdown.
- **Ngữ cảnh**: Inline Assistant không có khả năng phân tích toàn bộ repository để refactor đồng bộ nhiều file phức tạp.
- **Năng suất**: Viết tài liệu API trong IDE sẽ kém hiệu quả hơn so với Web Chat vốn chuyên về ngôn ngữ.

---

## Kết luận

Phương án C là lựa chọn tối ưu vì:
- Giữ ngữ cảnh phù hợp cho từng loại tác vụ.
- Giảm thiểu chuyển đổi ngữ cảnh không cần thiết.
- Tận dụng tối đa thế mạnh chuyên biệt của từng công cụ.
