# BÀI 3: Đọc hiểu & Dò lỗi qua Prompt (Phát hiện Ảo giác AI - Hallucination)

## Giải thích nguyên lý sinh lỗi ảo giác

Khi người dùng đưa vào prompt một phương thức không tồn tại (ví dụ: `StringUtils.hasSpecialCharacters()`), AI có xu hướng:
- **Dựa vào ngữ cảnh quen thuộc**: Thư viện Apache Commons Lang rất phổ biến, AI biết lớp `StringUtils` có nhiều phương thức tiện ích (như `isBlank`, `containsAny`, `capitalize`...), nên dễ suy đoán rằng một phương thức kiểm tra ký tự đặc biệt cũng tồn tại.
- **Tạo ra câu trả lời hợp lý về mặt ngôn ngữ**: AI thường cố gắng "lấp đầy khoảng trống" bằng cách bịa ra API nghe có vẻ hợp lý, dẫn đến **ảo giác (hallucination)**.
- **Hậu quả**: Mã sinh ra sẽ không biên dịch được, gây mất thời gian cho lập trình viên khi phải dò lại tài liệu chính thống.

---

## Prompt tối ưu mới

"Hãy viết cho tôi một hàm Java kiểm tra xem một chuỗi có chứa ký tự đặc biệt hay không.  
Yêu cầu:  
- Chỉ sử dụng API chính thức, đã được kiểm chứng của thư viện chuẩn Java hoặc thư viện phổ biến như Apache Commons Lang.  
- Không được bịa ra phương thức không tồn tại.  
- Phải giải thích cơ sở hoặc dẫn nguồn tài liệu chính thống (ví dụ: Java `Pattern`/`Matcher` trong gói `java.util.regex`, hoặc phương thức `StringUtils.containsAny()` trong Apache Commons Lang) để chứng minh phương thức đó thực sự tồn tại."

---

## Mã nguồn Java an toàn

```java
import java.util.regex.Pattern;
import java.util.regex.Matcher;

public class SpecialCharacterChecker {

    // Sử dụng regex để kiểm tra ký tự đặc biệt
    // Theo tài liệu chính thức của Java: java.util.regex.Pattern
    // https://docs.oracle.com/javase/8/docs/api/java/util/regex/Pattern.html
    private static final Pattern SPECIAL_CHAR_PATTERN = Pattern.compile("[^a-zA-Z0-9]");

    public static boolean hasSpecialCharacters(String input) {
        if (input == null) {
            return false;
        }
        Matcher matcher = SPECIAL_CHAR_PATTERN.matcher(input);
        return matcher.find();
    }

    public static void main(String[] args) {
        System.out.println(hasSpecialCharacters("HelloWorld"));   // false
        System.out.println(hasSpecialCharacters("Hello@World"));  // true
    }
}
