# BÀI 2: Tối ưu Prompt (Bảo mật thông tin nhạy cảm)

## Prompt sau khi tối ưu

"Hãy viết cho tôi class `VNPayPaymentService` bằng Java để thực hiện thanh toán trực tuyến qua VNPay.  
Yêu cầu nghiêm ngặt:  
- Tuyệt đối không hardcode API Key hay bất kỳ thông tin nhạy cảm nào trong mã nguồn.  
- Sử dụng biến môi trường (`System.getenv()`) để nạp khóa bí mật.  
- Nếu biến môi trường bị thiếu (null hoặc rỗng), phải ném ra ngoại lệ phù hợp để đảm bảo an toàn hệ thống khi vận hành."

---

## Mã nguồn Java hoàn chỉnh, an toàn

```java
public class VNPayConfig {

    // Nạp khóa bí mật từ biến môi trường
    public static final String HASH_SECRET;

    public static final String VNP_URL = "https://sandbox.vnpayment.vn/paymentv2/vpcpay.html";

    static {
        HASH_SECRET = System.getenv("VNPAY_HASH_SECRET");
        if (HASH_SECRET == null || HASH_SECRET.trim().isEmpty()) {
            throw new IllegalStateException("Environment variable VNPAY_HASH_SECRET is missing or empty. Please configure it before running the application.");
        }
    }
}

public class VNPayPaymentService {

    public String createPaymentUrl(String orderId, long amount, String returnUrl) {
        // Ví dụ logic tạo URL thanh toán
        String baseUrl = VNPayConfig.VNP_URL;
        StringBuilder paymentUrl = new StringBuilder(baseUrl);

        // Thêm tham số cơ bản
        paymentUrl.append("?orderId=").append(orderId);
        paymentUrl.append("&amount=").append(amount);
        paymentUrl.append("&returnUrl=").append(returnUrl);

        // Sinh chữ ký bảo mật (giả lập)
        String signature = generateSignature(orderId, amount, returnUrl);
        paymentUrl.append("&secureHash=").append(signature);

        return paymentUrl.toString();
    }

    private String generateSignature(String orderId, long amount, String returnUrl) {
        // Logic ký dữ liệu bằng HASH_SECRET
        // Ở đây chỉ minh họa, thực tế cần dùng HMAC SHA256 hoặc SHA512
        String data = orderId + "|" + amount + "|" + returnUrl;
        return Integer.toHexString((data + VNPayConfig.HASH_SECRET).hashCode());
    }
}
