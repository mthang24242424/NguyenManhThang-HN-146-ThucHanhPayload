# BÀI 5: Sáng tạo (Thiết kế Quy trình & Prompt Kiểm chứng Đầu ra - AI Verifier)

## Bối cảnh & Ý đồ thiết kế
Trong hệ thống bán vé trực tuyến "GreenBus", tính năng kiểm tra mã số vé (Ticket Code) là quan trọng để đảm bảo dữ liệu hợp lệ và ngăn chặn gian lận.  
Quy trình 2 bước được thiết kế nhằm:
1. **Sinh mã nguồn (Code Generation)**: AI tạo ra lớp `TicketValidator` theo quy tắc nghiệp vụ đã định.  
2. **Kiểm chứng độc lập (AI Auditing)**: Một AI khác đóng vai trò kiểm thử/kiểm toán, rà soát mã nguồn để phát hiện lỗi logic tiềm ẩn, từ đó tối ưu lại mã.

---

## Bước 1: Prompt sinh mã nguồn
"Hãy viết cho tôi lớp `TicketValidator` bằng Java để kiểm tra tính hợp lệ của mã vé xe khách theo các quy tắc sau:  
- Mã vé bắt buộc bắt đầu bằng tiền tố `BUS-`.  
- Tiếp theo là mã tỉnh/thành phố gồm đúng 2 ký tự chữ in hoa.  
- Tiếp theo là dấu gạch ngang `-` và 6 chữ số biểu diễn ngày đi xe theo định dạng `YYMMDD`.  
- Ngày đi xe không được là ngày trong quá khứ (phải >= ngày hiện tại của hệ thống).  
- Phải xử lý các trường hợp biên: mã vé null, rỗng, định dạng ngày tháng không hợp lệ (ví dụ ngày 32 tháng 13), hoặc ngày đi trong quá khứ.  
Yêu cầu: Viết lớp `TicketValidator` với phương thức `boolean isValid(String ticketCode)`."

## Bước 2: Prompt kiểm chứng độc lập
"Đóng vai trò là kỹ sư kiểm thử/kiểm toán độc lập. Đây là mã nguồn Java lớp `TicketValidator` do AI sinh ra.  
Nhiệm vụ của bạn:  
- Rà soát và phản biện, tìm ra các lỗi logic tiềm ẩn.  
- Ví dụ: xử lý ngày tháng có gặp lỗi khi chuyển giao năm mới, vấn đề múi giờ hệ thống, NullPointerException khi cắt chuỗi, hoặc regex chưa chặt chẽ.  
- Đưa ra khuyến nghị sửa đổi, ưu tiên sử dụng API hiện đại như `java.time.LocalDate` để đảm bảo tính chính xác."

## Minh chứng thực tế (Text Log)

### Mã nguồn Java sinh ra lần đầu (Bước 1)
```java
import java.text.ParseException;
import java.text.SimpleDateFormat;
import java.util.Date;

public class TicketValidator {

    public boolean isValid(String ticketCode) {
        if (ticketCode == null || ticketCode.trim().isEmpty()) {
            return false;
        }

        if (!ticketCode.startsWith("BUS-")) {
            return false;
        }

        String[] parts = ticketCode.split("-");
        if (parts.length != 3) {
            return false;
        }

        String cityCode = parts[1];
        if (cityCode.length() != 2 || !cityCode.matches("[A-Z]{2}")) {
            return false;
        }

        String datePart = parts[2];
        if (!datePart.matches("\\d{6}")) {
            return false;
        }

        SimpleDateFormat sdf = new SimpleDateFormat("yyMMdd");
        sdf.setLenient(false);
        try {
            Date travelDate = sdf.parse(datePart);
            Date today = new Date();
            if (travelDate.before(today)) {
                return false;
            }
        } catch (ParseException e) {
            return false;
        }

        return true;
    }
}
