# BÀI TẬP SÁNG TẠO - KHỞI TẠO WORKFLOW SRS HOÀN CHỈNH

## 1. Phân tích & Thiết kế nghiệp vụ

### Yêu cầu thô từ khách hàng

> "Tôi muốn hệ thống tự động gợi ý các sản phẩm liên quan khi người dùng đang xem một món đồ, dựa trên lịch sử mua hàng của họ."

### Mục tiêu nghiệp vụ

Xây dựng module AI Product Recommendation giúp đề xuất các sản phẩm phù hợp với sở thích và hành vi mua sắm của người dùng nhằm tăng tỷ lệ mua hàng và doanh thu.

### Input

* User ID
* Product ID đang được xem
* Lịch sử mua hàng của người dùng
* Danh sách sản phẩm hiện có trong hệ thống

### Output

* Danh sách sản phẩm được gợi ý
* Điểm phù hợp (Recommendation Score)
* Thứ tự ưu tiên hiển thị

### Luồng xử lý nghiệp vụ

```ascii
+------------------+
| User xem sản phẩm|
+---------+--------+
          |
          v
+------------------+
| Lấy User ID      |
| và Product ID    |
+---------+--------+
          |
          v
+-------------------------+
| Truy xuất lịch sử mua   |
| hàng của người dùng     |
+------------+------------+
             |
             v
+-------------------------+
| Phân tích sở thích      |
| và hành vi mua hàng     |
+------------+------------+
             |
             v
+-------------------------+
| Tìm sản phẩm liên quan  |
| trong cơ sở dữ liệu     |
+------------+------------+
             |
             v
+-------------------------+
| Tính Recommendation     |
| Score                  |
+------------+------------+
             |
             v
+-------------------------+
| Sắp xếp và trả về       |
| danh sách gợi ý         |
+-------------------------+
```

## 2. Thiết kế Workflow Prompt

### Prompt 1 - Chuyển đổi yêu cầu thô thành đặc tả nghiệp vụ

```text
Bạn là Business Analyst và System Analyst chuyên nghiệp.

Nhiệm vụ:
Phân tích yêu cầu sau:

"Tôi muốn hệ thống tự động gợi ý các sản phẩm liên quan khi người dùng đang xem một món đồ, dựa trên lịch sử mua hàng của họ."

Hãy:
1. Xác định mục tiêu nghiệp vụ.
2. Xác định Actor.
3. Xác định Input.
4. Xác định Output.
5. Mô tả luồng nghiệp vụ chi tiết.
6. Liệt kê các giả định và ràng buộc.

Trả lời theo định dạng tài liệu phân tích nghiệp vụ.
```

### Prompt 2 - Sinh Use Case Description

```text
Dựa trên phân tích nghiệp vụ ở trên.

Hãy tạo Use Case Description hoàn chỉnh gồm:

- Use Case ID
- Use Case Name
- Description
- Primary Actor
- Trigger
- Preconditions
- Main Flow
- Alternate Flow
- Exception Flow
- Postconditions

Xuất kết quả theo chuẩn SRS.
```

### Prompt 3 - Sinh Functional Requirements

```text
Dựa trên Use Case Description đã tạo.

Hãy sinh danh sách Functional Requirements.

Mỗi Requirement phải có:
- Requirement ID
- Requirement Description
- Priority (High/Medium/Low)

Đánh số dạng:
FR-001
FR-002
FR-003
...
```

### Prompt 4 - Sinh Data Dictionary

```text
Dựa trên Functional Requirements.

Hãy tạo Data Dictionary sơ bộ cho module AI Product Recommendation.

Bao gồm:

- Tên trường dữ liệu
- Kiểu dữ liệu
- Mô tả
- Ví dụ

Các thực thể tối thiểu:
- User
- Product
- PurchaseHistory
- Recommendation
```

### Prompt 5 - Tổng hợp thành SRS hoàn chỉnh

```text
Dựa trên toàn bộ kết quả trước đó.

Hãy tổng hợp thành tài liệu SRS hoàn chỉnh gồm:

1. Introduction
2. Scope
3. Use Case Description
4. Functional Requirements
5. Non-Functional Requirements
6. Data Dictionary
7. Assumptions
8. Constraints

Xuất kết quả dưới dạng Markdown.
```

## 3. Kiểm chứng thực tế (Minh chứng)

### User

```text
Bạn là Business Analyst và System Analyst chuyên nghiệp.

Nhiệm vụ:
Phân tích yêu cầu sau:

"Tôi muốn hệ thống tự động gợi ý các sản phẩm liên quan khi người dùng đang xem một món đồ, dựa trên lịch sử mua hàng của họ."

Hãy:
1. Xác định mục tiêu nghiệp vụ.
2. Xác định Actor.
3. Xác định Input.
4. Xác định Output.
5. Mô tả luồng nghiệp vụ chi tiết.
6. Liệt kê các giả định và ràng buộc.

Trả lời theo định dạng tài liệu phân tích nghiệp vụ.
```

### AI

```text
Mục tiêu nghiệp vụ:
Tăng tỷ lệ chuyển đổi mua hàng bằng cách đề xuất các sản phẩm phù hợp với sở thích người dùng.

Actor:
- Khách hàng
- Hệ thống Recommendation Engine

Input:
- User ID
- Product ID đang xem
- Purchase History
- Product Catalog

Output:
- Danh sách sản phẩm đề xuất
- Recommendation Score

Luồng nghiệp vụ:
1. Người dùng truy cập trang chi tiết sản phẩm.
2. Hệ thống ghi nhận Product ID.
3. Hệ thống truy xuất lịch sử mua hàng của người dùng.
4. AI phân tích hành vi mua sắm.
5. Hệ thống tìm các sản phẩm liên quan.
6. Tính điểm phù hợp.
7. Trả về danh sách đề xuất.

Giả định:
- Người dùng đã đăng nhập.
- Có dữ liệu lịch sử mua hàng.

Ràng buộc:
- Thời gian phản hồi dưới 2 giây.
- Chỉ hiển thị sản phẩm còn hàng.
```

### User

```text
Dựa trên phân tích trên, hãy tạo Use Case Description hoàn chỉnh.
```

### AI

```text
Use Case ID: UC-REC-001

Use Case Name:
Generate Product Recommendations

Primary Actor:
Customer

Description:
Hệ thống tự động đề xuất sản phẩm phù hợp dựa trên sản phẩm đang xem và lịch sử mua hàng.

Trigger:
Người dùng mở trang chi tiết sản phẩm.

Preconditions:
- Người dùng đăng nhập.
- Có dữ liệu sản phẩm.

Main Flow:
1. Người dùng xem sản phẩm.
2. Hệ thống lấy lịch sử mua hàng.
3. Hệ thống phân tích dữ liệu.
4. Hệ thống sinh danh sách đề xuất.
5. Hiển thị kết quả.

Postconditions:
Danh sách sản phẩm đề xuất được hiển thị.
```

### Kết quả

Workflow Prompt đã chuyển đổi thành công yêu cầu thô của khách hàng thành các thành phần quan trọng của tài liệu SRS gồm:

* Use Case Description
* Functional Requirements
* Data Dictionary
* Luồng nghiệp vụ
* Assumptions & Constraints

Qua đó chứng minh khả năng sử dụng AI để hỗ trợ quá trình Software Requirement Specification từ yêu cầu ban đầu chưa có tài liệu.
